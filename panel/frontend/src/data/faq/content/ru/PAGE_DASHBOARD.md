# Дашборд

Обзор всего флота в одной сетке: что онлайн, где растёт нагрузка, что упало.

## Что на экране

- **Сводка сверху** — суммарные CPU, RAM и скорость сети по всем онлайн-серверам. CPU считается с весом по числу ядер, поэтому 100% на восьмиядерной ноде весят больше, чем на двухъядерной. Офлайн-серверы в сводку не входят, чтобы устаревшие цифры её не завышали. Клик по плитке раскрывает график этого показателя по всему парку — за час, сутки, неделю, месяц или год; повторный клик сворачивает.
- **Карточка сервера** — статус, CPU, RAM, диск, скорость сети, Load Average, IP (клик копирует адрес).
- **Папки** — группировка карточек, сворачиваются для экономии места.
- Клик по карточке открывает детали сервера с графиками, процессами и терминалом.

## Как читать показатели

| Показатель | На что смотреть |
|---|---|
| Зелёный кружок | Агент онлайн и шлёт метрики |
| Красный кружок | Нода недоступна: сеть, упавший агент, файрвол или мёртвый SOCKS5-прокси |
| Load Average | Выше числа ядер — процессы ждут очереди. Короткие пики нормальны |
| Скорость сети | Считается только по физическим интерфейсам: docker-мосты и veth исключены, иначе трафик считался бы дважды |

## Полезно знать

- Карточки перетаскиваются мышью — и между папками, и внутри папки. Порядок сохраняется на сервере и одинаков для всех администраторов.
- Вид (сетка или список, компактный или подробный) хранится в браузере, у каждого администратора свой.
- Интервал обновления метрик задаётся в настройках панели, по умолчанию 10 секунд.
- Красный статус со старыми цифрами — это последние успешные метрики: панель их не стирает, чтобы было видно состояние на момент падения.
