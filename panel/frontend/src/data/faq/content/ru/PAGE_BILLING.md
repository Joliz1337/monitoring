# Оплата серверов

Учёт того, когда за какой сервер платить, чтобы ничего не отключилось неожиданно.

## Три типа учёта

| Тип | Как считается срок |
|---|---|
| Помесячный | Вы указываете дату, до которой оплачено, либо число оплаченных дней. Цену за месяц можно добавить по желанию — тогда сервер учитывается в расходе в месяц |
| Ресурсный | Есть баланс и стоимость в день — панель сама считает, на сколько хватит |
| Облако | Баланс и остаток срока подтягиваются из API провайдера: Yandex Cloud, Selectel, Timeweb Cloud или VK Cloud |

## Что можно

- Добавить любой сервер или хостинг, даже тот, что не подключён к мониторингу.
- Продлить срок на нужное число дней или пополнить баланс — ещё до подтверждения видно, сколько дней и до какой даты будет оплачено в итоге.
- Для облачных аккаунтов — обновить данные кнопкой в карточке или сразу все кнопкой «Обновить облака» в шапке. Только что добавленный облачный проект панель обновляет сама.
- Прикинуть пополнение облака: «Рассчитать» покажет, сколько внести, чтобы хватило на нужное число дней, или на сколько хватит конкретной суммы.
- Получать напоминания в Telegram заранее, через того же бота, что и алерты.
- Держать заметки: реквизиты, номер тарифа, у кого куплен сервер.

## Ключи доступа облаков

- **Yandex Cloud** — ID биллинг-аккаунта и авторизованный ключ сервисного аккаунта, по шагам ниже. Новые OAuth-токены Yandex Cloud не принимает с 1 июня 2026 года. Выданный раньше токен в старом проекте работает, пока не истечёт, но лучше заменить его ключом заранее.
- **Selectel** — один статический API-ключ: в панели Selectel «Профиль → Доступ → API-ключи». Ключ показывается один раз, скопируйте его сразу. Пользователь, которому принадлежит ключ, должен видеть раздел «Биллинг».
- **Timeweb Cloud** — API-токен из раздела «API и Terraform» панели Timeweb Cloud.
- **VK Cloud** — логин, пароль и Project ID (личный кабинет → «Настройки проекта» → «Доступ по API»). Ключей API у VK Cloud нет, поэтому панель сама получает временный токен при каждой проверке. Подойдёт почта аккаунта или сервисная учётная запись, которую можно завести только для панели. В аккаунте должны быть включены двухфакторная аутентификация и доступ по API.

Как подключить Yandex Cloud:

1. В любом каталоге облака создайте сервисный аккаунт.
2. Откройте [center.yandex.cloud/billing/accounts](https://center.yandex.cloud/billing/accounts), выберите платёжный аккаунт, слева «Управление доступом» → «Назначить роли». Выберите сервисный аккаунт и добавьте ему роль `billing.accounts.viewer`. Роль нужна именно здесь: если выдать её в правах каталога или облака, Yandex ответит панели «Forbidden: need billing.accounts.viewer role». Если сервисного аккаунта нет в списке, выдайте ему роль на всю организацию в Cloud Center — она действует на все её платёжные аккаунты.
3. В карточке сервисного аккаунта нажмите «Создать новый ключ» → «Создать авторизованный ключ» и скачайте JSON-файл.
4. Вставьте содержимое файла целиком в поле ключа и укажите ID платёжного аккаунта. После сохранения панель сразу подтянет баланс и расход.

Ключи хранятся в базе в зашифрованном виде и обратно в интерфейс не отдаются: в форме редактирования поле пустое, пустым его и оставляют, если менять ключ не нужно.

Если API провайдера не открывается с адреса панели или аккаунты не должны ходить к провайдеру с одного IP, у облачного проекта можно указать SOCKS5-прокси в формате `ip:port` или `ip:port@login:pass`. Через него пойдут все запросы панели по этому проекту. Если прокси не отвечает, ошибка в карточке так и скажет: «via proxy ip:port».

## Полезно знать

- Для ресурсного типа важна честная стоимость в день: панель просто делит остаток баланса на неё.
- Порог остатка — сумма, ниже которой баланс тратить нельзя: срок считается до неё, а не до нуля.
- У Yandex Cloud расход считается по факту потребления за последние три дня, поэтому после резкого роста нагрузки число подстраивается за пару дней.
- У Selectel срок берётся у самого Selectel: его прогноз «на сколько дней хватит баланса» показывается как есть, а расход в день — это остаток, делённый на эти дни.
- У Timeweb Cloud истории списаний в API нет, поэтому панель сама запоминает баланс при каждой проверке и считает расход по его снижению; пополнения на расчёт не влияют. Первые часы после добавления, пока истории мало, показывается расход по текущему тарифу.
- У VK Cloud баланс показывается вместе с бонусами, потому что бонусы списываются первыми. Расход — средний за последние три полных дня по отчёту о потреблении.
- Сводка сверху показывает расход в месяц, сумму балансов и сколько проектов истекает в ближайшую неделю. Разные валюты не складываются в одно число — они перечислены отдельно.
- Просроченные и заканчивающиеся серверы подсвечиваются — их видно сразу при входе на страницу.
- Это учётная страница: она никого не оплачивает и не продлевает автоматически.
