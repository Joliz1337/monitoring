# Remnawave

Интеграция с панелью Remnawave: статистика подключений пользователей, их устройства и поиск аномалий. Данные берутся напрямую из API Remnawave, агенты на нодах в этом не участвуют.

## Что на странице

- Сводка: сколько уникальных пользователей, адресов и устройств.
- Топ пользователей с фильтром по статусу подписки и по конкретному адресу.
- Карточка пользователя: с каких адресов заходил и какие устройства зарегистрированы.
- Настройки подключения к Remnawave и список игнорируемых пользователей.

## Аномалии

- **По устройствам** — одно устройство используется несколькими аккаунтами или аккаунт непрерывно меняет устройства.
- **По адресам** — пользователь подключается с непривычных адресов, что похоже на передачу подписки.
- **По трафику** — потребление выше заданного порога, подтверждённое несколько раз подряд, чтобы разовый всплеск не давал ложной тревоги.

Уведомления идут в Telegram: либо через общего бота алертов, либо через отдельного, если он задан.

## Настройки проверок

Каждая проверка выключается своим тумблером, остальные продолжают работать. Настройки проверки IP:

- **Запас IP** — сколько лишних адресов прощаем. Лимит устройств 3, запас 2 — тревога начнётся с 6 адресов.
- **Подтверждений** — сколько раз подряд превышение должно повториться, прежде чем придёт уведомление. Один случайный всплеск тревоги не поднимет.
- **Запас ASN** — то же, но по провайдерам. Wi-Fi дома и мобильный интернет у одного человека — уже два провайдера, это нормально. Уведомление придёт, только если провайдеров больше, чем лимит устройств плюс этот запас.

**Известные клиенты** — список приложений, которые считаются нормальными. Подключение с приложением не из списка — тревога «Неизвестный User-Agent». Своё приложение добавляется одной строкой, например `MyApp/`. Очистите поле и сохраните — вернётся стандартный список.

## Полезно знать

- Список пользователей кэшируется и обновляется примерно раз в полчаса; статистика подключений пересобирается по своему интервалу и полностью заменяется — это срез «сейчас», а не накопительная история.
- Пустая статистика — проверьте адрес и токен API в настройках кнопкой проверки подключения.
- Пользователей, которым аномалии не нужны (свои тестовые аккаунты, общие подписки), добавляйте в игнорируемые.
- Это только наблюдение: банами по торрентам занимается отдельная страница блокировщика.
