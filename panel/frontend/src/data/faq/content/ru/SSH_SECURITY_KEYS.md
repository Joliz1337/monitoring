# SSH-ключи

Публичные ключи для входа без пароля: перебрать ключ практически невозможно, в отличие от пароля.

## Как добавить

1. Создайте пару, если её нет: `ssh-keygen -t ed25519 -C "почта"`.
2. Возьмите **публичную** часть: `cat ~/.ssh/id_ed25519.pub` — строка начинается с `ssh-ed25519`.
3. Вставьте её целиком и выберите серверы.
4. Проверьте вход отдельной сессией: `ssh -i ~/.ssh/id_ed25519 root@адрес`.

## Полезно знать

- Загружать нужно только `.pub`. Приватный ключ (`id_ed25519` без расширения) не передаётся никуда и никогда.
- Ed25519 предпочтительнее RSA: короче, быстрее и надёжнее. RSA приемлем от 4096 бит.
- Комментарий в конце строки — произвольный, по нему удобно понимать, чей это ключ.
- Удаление ключа из панели убирает его из `authorized_keys` на выбранных нодах; активные сессии при этом не обрываются.
- Ключ добавлен, а вход не работает — почти всегда права: каталог `.ssh` должен быть 700, файл `authorized_keys` — 600.
