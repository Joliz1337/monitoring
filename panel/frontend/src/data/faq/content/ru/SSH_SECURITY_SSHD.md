# Параметры sshd

Настройки демона SSH. После применения панель перезапускает службу — активные сессии при этом не рвутся.

| Параметр | Смысл и рекомендация |
|---|---|
| Порт | По умолчанию 22. Смена уменьшает шум сканеров в логах, но защитой не является |
| Вход под root | `prohibit-password` — только по ключу (обычный выбор), `no` — запрещён совсем, `yes` — опасно |
| Вход по паролю | Отключайте только после проверенного входа по ключу |
| Число попыток авторизации | 3–4 достаточно; меньше попыток — меньше шансов у перебора |
| Таймаут простоя | Автоматически закрывает забытые сессии |
| Аутентификация по ключу | Должна быть включена всегда |

## Полезно знать

- Изменения проверяются перед применением: конфиг с синтаксической ошибкой не сохранится.
- Смена порта не открывает его в файрволе — сделайте это заранее, иначе после перезапуска попасть на сервер будет нельзя.
- Текущая сессия переживает перезапуск sshd, поэтому сразу проверяйте новый доступ в отдельном окне — пока старое подключение живо, ошибку ещё можно исправить.
- Пресет «максимальный» отключает пароли полностью: убедитесь, что ключи разложены на все ноды, к которым он применяется.
