# Сроки, баланс и продление

Как считается дата, после которой сервер перестанет быть оплаченным.

## Поля

| Поле | Смысл |
|---|---|
| Оплачено до | Конечная дата. Можно ввести датой или числом оплаченных дней |
| Стоимость в день | Для ресурсного типа: сколько списывается ежедневно |
| Баланс | Текущий остаток средств на аккаунте хостера |
| Валюта | Для отображения сумм |
| Заметки | Реквизиты, тариф, кто оплачивает |

Срок для ресурсного типа = баланс, делённый на стоимость в день. Пополнение баланса и продление на дни сразу двигают дату окончания.

## Полезно знать

- Напоминание приходит заранее — так, чтобы успеть оплатить, а не постфактум.
- Если у хостера оплата списывается неравномерно (почасовая тарификация, разные машины), точнее вести учёт ресурсным типом с усреднённой стоимостью в день.
- Для Yandex Cloud баланс подтягивается автоматически, руками его менять не нужно; ручное пополнение пригодится, только когда деньги внесены, но синхронизация ещё не прошла.
- Сервер удалён из мониторинга — запись об оплате остаётся: это независимый учёт.
