# Триггер: TCP-состояния

Следит за числом соединений в каждом состоянии. У каждого состояния свой порог и свой выключатель.

## Что означают состояния

| Состояние | О чём говорит рост |
|---|---|
| ESTABLISHED | Активные соединения: наплыв клиентов или DDoS. Резкое падение — сервис умер |
| LISTEN | Число слушающих портов; меняется редко, рост означает новые сервисы |
| TIME_WAIT | Недавно закрытые. Рост в разы — приложение не переиспользует соединения, нет keep-alive |
| CLOSE_WAIT | Удалённая сторона закрыла, локальная нет. Постоянный рост — приложение не закрывает сокеты |
| SYN_SENT | Исходящие попытки подключения. Много и надолго — недоступен апстрим или проблемы с DNS |
| SYN_RECV | Входящие полуоткрытые. Резкий рост — классический SYN-флуд |
| FIN_WAIT | Закрывающиеся соединения |

## Полезно знать

- Десяток CLOSE_WAIT — норма; тревожно, когда число только растёт и не спадает.
- На нагруженных нодах десятки тысяч TIME_WAIT нормальны: ставьте высокий порог, иначе алерты будут постоянными.
- Всплеск SYN_RECV вместе с ростом трафика — повод посмотреть на анти-DDoS: watchdog реагирует на такие атаки сам.
- Значения берутся из статистики ядра; на сильно урезанных ядрах часть счётчиков может быть недоступна.
