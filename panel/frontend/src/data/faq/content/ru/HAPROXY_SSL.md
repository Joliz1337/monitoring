# Сертификаты HAProxy

TLS-сертификаты на конкретной ноде: выпуск через Let's Encrypt, загрузка своих, продление.

## Выпуск через Let's Encrypt

1. Домен должен указывать A- или AAAA-записью на этот сервер.
2. Порт 80 должен быть открыт — по нему проходит проверка владения доменом.
3. Укажите домен и почту, запустите выпуск — панель выполнит проверку сама.
4. Пропишите домен сертификата в правиле HAProxy и перезагрузите конфиг.

Свой сертификат загружается файлом: подойдёт `.pem`, содержащий цепочку и приватный ключ, либо два файла отдельно — панель объединит их сама.

## Полезно знать

- Сертификаты Let's Encrypt живут 90 дней; пометка «скоро истекает» появляется за 30 дней.
- В деталях видно, кому и кем выдан, все домены сертификата и дату окончания.
- Wildcard-сертификат так выпустить нельзя: для `*.example.com` нужна проверка через DNS — это отдельная страница Wildcard SSL, которая ещё и раскладывает сертификат по всем нодам сразу.

## Если выпуск не проходит

| Причина | Как проверить |
|---|---|
| Домен не указывает на сервер | `dig +short домен` — адрес должен совпадать с IP ноды |
| Порт 80 закрыт или занят | `ss -tlnp \| grep :80` на ноде, правила файрвола |
| Исчерпан лимит Let's Encrypt | Пять неудачных попыток в час на домен — подождите |
| Сертификат выпущен, но не применился | Он должен быть указан в правиле, после чего нужна перезагрузка конфига |
