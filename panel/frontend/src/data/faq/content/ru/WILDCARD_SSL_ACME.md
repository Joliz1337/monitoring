# Выпуск через DNS-проверку

Wildcard-сертификат нельзя получить обычной проверкой по HTTP: Let's Encrypt требует подтвердить владение доменом через DNS. Панель делает это автоматически через API Cloudflare.

## Что происходит при выпуске

1. Панель запрашивает сертификат на `*.домен` и получает от Let's Encrypt проверочное значение.
2. Через API Cloudflare создаётся временная TXT-запись `_acme-challenge` в вашей зоне.
3. Let's Encrypt проверяет запись, панель получает сертификат, временная запись удаляется.

## Требования к токену Cloudflare

Токен должен иметь право читать зону и редактировать её DNS-записи. Ограничьте его конкретной зоной — этого достаточно, полный доступ к аккаунту не нужен.

## Частые причины неудачи

| Симптом | Причина |
|---|---|
| Ошибка авторизации | Токен неверный, отозван или не имеет прав на редактирование DNS |
| Зона не найдена | Домен не обслуживается в Cloudflare или указан с опечаткой |
| Проверка не прошла | DNS-запись ещё не разошлась — обычно помогает повторная попытка через несколько минут |
| Превышен лимит | У Let's Encrypt есть ограничение на число выпусков для домена: подождите и не выпускайте сертификат повторно без нужды |

## Полезно знать

- Продление идёт тем же способом и не требует вашего участия; панель начинает продлевать заранее, а не в последний день.
- Сертификат живёт 90 дней — это ограничение Let's Encrypt, увеличить срок нельзя.
- При повторных выпусках подряд легко упереться в лимиты, поэтому для проверки конфигурации лучше пользоваться уже выпущенным сертификатом.
