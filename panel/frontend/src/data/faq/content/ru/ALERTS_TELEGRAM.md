# Telegram-уведомления

Единственный канал доставки алертов. Настраивается за пару минут.

## Настройка

1. В Telegram откройте **@BotFather**, отправьте `/newbot`, придумайте имя.
2. Полученный **Bot Token** (вида `1234567890:AaBbCc...`) вставьте в поле токена.
3. Создайте группу и добавьте туда бота — либо используйте личный чат с ним.
4. Узнайте **Chat ID**: через **@userinfobot** или открыв `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдя `"chat":{"id": ...}`.
5. Вставьте Chat ID и нажмите проверку — должно прийти тестовое сообщение.

## Полезно знать

- Chat ID группы — отрицательное число (`-1001234...`), личного чата — положительное.
- Бот в группе должен иметь право писать сообщения; если в группе включены темы, он должен видеть нужную.
- Токен секретный: с ним можно писать от имени бота. Утёк — отзовите в @BotFather.
- Чат один на всю панель. Нужно несколько получателей — заведите группу и добавьте туда людей.

## Ошибки проверки

| Ответ | Причина |
|---|---|
| `401 Unauthorized` | Неверный или отозванный токен |
| `chat not found` | Неверный Chat ID или бот не добавлен в чат |
| `bot was blocked by the user` | Личный чат заблокирован пользователем |
| Таймаут | С сервера панели нет доступа к `api.telegram.org` |
