# Отслеживание портов

Позволяет видеть объём трафика по каждому интересному порту отдельно, а не только суммарно по интерфейсу.

## Как пользоваться

Добавьте порт в список — данные начнут накапливаться со следующего сбора, за минуту-две появятся первые цифры. Удаление порта из списка прекращает учёт, уже собранная история остаётся.

Для добавления одного порта на десятки нод есть массовые операции.

## Полезно знать

- Учёт ведётся на ноде правилами подсчёта пакетов, поэтому лишние порты — лишние правила: держите список коротким, только по значимым сервисам.
- Порт добавлен, а трафика нет — проверьте, что сервис вообще слушает этот порт и что трафик не идёт через другой (например, клиенты подключаются по 443, а не по указанному).
- Данные по портам не заменяют общий счётчик интерфейса: сумма по портам всегда меньше, потому что часть трафика идёт мимо отслеживаемых.
