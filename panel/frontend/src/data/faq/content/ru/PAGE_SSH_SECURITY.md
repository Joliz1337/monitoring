# SSH-безопасность

Настройки sshd, защита от перебора и ключи доступа — сразу на всех нодах из одного места.

## Что можно

- Править параметры sshd: порт, вход под root, вход по паролю, число попыток, таймауты.
- Включать и настраивать Fail2ban, смотреть забаненные адреса и снимать баны.
- Раскладывать публичные ключи по серверам.
- Применять готовые пресеты («рекомендуемый» и «максимальный») или сохранить свой набор настроек как пресет.

Массовые операции идут потоком: результат по каждой ноде появляется по мере выполнения, а не после завершения всех.

## Порядок безопасной настройки

1. Сначала загрузите ключ и **проверьте вход по нему** отдельной сессией, не закрывая текущую.
2. Только потом отключайте вход по паролю.
3. Меняя порт, сначала откройте новый в файрволе, и лишь затем правьте sshd.

## Полезно знать

- Панель проверяет конфиг перед применением, но защититься от логической ошибки (отключили пароль, не добавив ключ) она не может.
- Потеряли доступ — спасёт только консоль хостера: там правится `/etc/ssh/sshd_config` и перезапускается служба.
- Порт 9100 к SSH отношения не имеет: он нужен панели для связи с агентом, закрывать его нельзя.
