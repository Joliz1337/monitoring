# Файрвол ноды

Правила UFW на конкретном сервере: что разрешено, откуда и в какую сторону.

## Параметры правила

| Поле | Значения |
|---|---|
| Порт | 1–65535 или любой |
| Протокол | TCP, UDP или любой |
| Действие | Разрешить или запретить |
| Направление | Входящий или исходящий трафик |
| Источник | Конкретный IP, подсеть вида `10.0.0.0/24` или `0.0.0.0/0` (отовсюду) |

Типовой набор для VPN-ноды: SSH только со своего адреса, 443 всем, порт 9100 — только с IP панели.

## Полезно знать

- Правила действуют на одну ноду. Нужен одинаковый набор на всём флоте — используйте профили файрвола: там правила задаются один раз и раскатываются с проверкой и откатом.
- Порт открыт, а сервис недоступен — убедитесь, что приложение вообще слушает: `ss -tlnp | grep :443`.
- Закрыли себе SSH — поможет только консоль хостера: `ufw disable`, затем вернуть правила через панель.
- Блок-лист адресов — это другое: он работает через ipset на всех нодах сразу и не связан с этими правилами.
