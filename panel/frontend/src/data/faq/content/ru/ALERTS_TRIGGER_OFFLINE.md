# Триггер: сервер офлайн

Самый важный алерт: нода перестала отвечать. Когда она возвращается, приходит отдельное сообщение о восстановлении.

## Параметры

| Параметр | Смысл |
|---|---|
| Число неудач подряд | Сколько проверок должно провалиться до объявления офлайн. По умолчанию 3 |
| Интервал проверки | Как часто панель опрашивает ноды — общая настройка алертера, по умолчанию раз в минуту |
| Пауза | Интервал между повторными сообщениями |

## Полезно знать

- Время до алерта считается просто: интервал проверки × число неудач. При проверке раз в минуту и трёх неудачах уведомление придёт примерно через три минуты.
- Ставить одну неудачу не стоит: единичный сетевой сбой между панелью и нодой даст ложную тревогу.
- Уведомление о восстановлении приходит автоматически, отдельно включать не нужно.
- Сервер числится офлайн, хотя доступен — нажмите «Тест» на странице «Серверы»: чаще всего это мёртвый SOCKS5-прокси, закрытый порт 9100 или упавший контейнер агента.
- Перезапуск панели не вызывает повторных уведомлений по уже лежащим серверам — состояние восстанавливается из истории.
