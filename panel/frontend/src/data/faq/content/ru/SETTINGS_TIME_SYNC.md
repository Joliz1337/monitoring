# Синхронизация времени

Ставит на всех нодах один часовой пояс и включает сверку часов по сети.

## Как работает

Панель раз в сутки проходит по активным нодам: выставляет выбранный часовой пояс, включает автоматическую сверку времени и запускает её принудительно. То же самое происходит сразу при добавлении новой ноды и при смене часового пояса в настройках. Синхронизацию можно запустить руками кнопкой.

## Зачем это нужно

- Логи с разных нод сопоставимы только при одинаковом времени.
- Расхождение часов ломает TLS-сертификаты, одноразовые коды и подписи запросов.
- Графики и алерты строятся по времени: уехавшие часы дают провалы и всплески на пустом месте.

## Полезно знать

- Часть хостеров блокирует сетевую сверку времени, и системная служба тихо не работает — здесь видно её реальное состояние по каждой ноде.
- Часовой пояс панели и часовой пояс серверов — разные настройки: первая меняет только отображение дат в интерфейсе.
- Расхождение в секунды на графиках незаметно, но для проверки подписей и одноразовых кодов критично: там счёт идёт на десятки секунд.
