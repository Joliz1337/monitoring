# Автобэкапы панели в Telegram

Панель по расписанию снимает дамп базы, вшивает в него весь `.env` панели,
шифрует набор паролем (AES-256), разбивает на тома < 50 МБ (лимит Telegram) и
отправляет их в приватный Telegram-канал. Настраивается в панели:
**Настройки → Автобэкапы в Telegram**.

## Настройка

1. Создать приватный Telegram-канал для бэкапов.
2. Создать бота (@BotFather) и добавить его в админы канала.
3. Узнать ID канала (формат `-100…`).
4. В панели включить автобэкапы, вписать токен бота, ID канала, пароль архива,
   расписание и размер тома. Кнопка «Тест канала» проверит доставку.

**Пароль архива храните отдельно** — без него набор не восстановить.

## Восстановление

1. Скачать все тома набора (`panel-backup_<дата>.enc.001`, `.002`, …) в одну папку.
2. Расшифровать в `.dump`:

   ```bash
   python3 tg-restore.py -o restored.dump ./volumes-dir/
   ```

3. Загрузить `restored.dump` в панели: **Настройки → Бэкап → Восстановить**.

Набор самодостаточен — несёт весь `.env` панели (включая ключ шифрования), поэтому
панель восстанавливается полностью, в том числе после переустановки с нуля.
Инфраструктурные значения (пароль БД, домен, порты) при восстановлении не
перезатираются; логин/JWT из бэкапа вступают в силу после перезапуска панели.
