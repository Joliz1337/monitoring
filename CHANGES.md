# Что нового

История изменений простым языком: что изменилось, что это даёт и нужно ли что-то делать. Обновиться можно в панели через раздел **Обновления** — настройки и данные при этом сохраняются.

Проект в статусе Stable: основной функционал устоялся, версии стабильного канала (`main`) сначала обкатываются в dev-канале. Канал переключается в настройках панели — выберите «Стабильный», если хотите получать только проверенные версии.

Анонсы обновлений, вопросы и обсуждение — в [Telegram-сообществе](https://t.me/+IClul20AJ7Y5MTFi).

## Панель 10.52.0

- **Можно выдать отдельный ключ установки для сервера, который настраивает кто-то другой.** До сих пор был только один общий ключ для подключения новых нод — один на весь парк серверов. Если его когда-нибудь получал посторонний (например, владелец арендованного сервера, который сам ставит агент), теоретически он мог использовать этот ключ, чтобы выдать себя за панель перед любой другой вашей нодой. Теперь в форме добавления сервера есть блок «Ключ под один сервер»: такой ключ выпускается персонально под одну ноду и не даёт доступа ни к чему больше.
- У персонального ключа есть срок действия — от 30 дней до 3 лет, задаётся при выпуске. По его истечении панель просто перестаёт видеть эту ноду; отозвать ключ раньше срока нельзя, только заранее ограничить его действие подходящим сроком.
- **Панель теперь видит настоящий IP-адрес посетителя.** Раньше все запросы к панели, прошедшие через её собственный веб-сервер, выглядели пришедшими с одного и того же служебного адреса. Из-за этого несколько неверных попыток входа от любого человека могли временно заблокировать вход всем, кто в этот момент пытался зайти в панель, — теперь блокируется только тот, кто действительно ошибается.
- **Подбор секретного адреса панели теперь тоже ограничен.** Раньше защита от перебора считала только неверные пароли — попытки угадать сам секретный адрес (UID) панели ничем не ограничивались. Теперь они учитываются точно так же: после 5 неудачных попыток IP блокируется на 15 минут.
- **Убран служебный адрес, показывавший состояние блокировок всем в интернете без пароля.** Он был нужен только для отладки, но был доступен кому угодно.
- **Закрыта возможность загрузить файл резервной копии на сервер без авторизации.** Раньше файл принимался и полностью сохранялся на диск, и только потом панель проверяла, авторизован ли отправитель. Теперь проверка происходит раньше, чем файл начинает загружаться.
- **Усилена защита от перебора на входе, проверке UID и восстановлении из бэкапа.** Добавлено ограничение частоты запросов — это дополнительный слой защиты поверх уже существующей блокировки по IP.
- **Закрыт ещё один служебный технический адрес**, показывавший статус панели без авторизации всем в интернете.

**Что делать:** ничего — обновите панель как обычно, все изменения применяются автоматически. Часть этой версии — исправления безопасности, поэтому обновиться стоит не откладывая. Общий ключ установки продолжает работать как раньше для ваших собственных серверов; новый блок «Ключ под один сервер» — дополнительная возможность для случаев, когда сервер настраивает кто-то другой.
